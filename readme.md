# Descrição do Projeto

O **Pensário** é uma plataforma digital desenvolvida para facilitar o acesso ao conhecimento filosófico. Seu objetivo é reunir e organizar conteúdos sobre grandes filósofos e suas ideias, apresentando resumos e reflexões de forma clara, acessível e organizada.

A plataforma busca tornar o estudo da filosofia mais simples e interessante, permitindo que os usuários explorem diferentes pensadores, conheçam suas principais contribuições e aprofundem seus conhecimentos.
